# Frontend–Backend Connectivity Checkpoint

## Completed scope

- Static React chat shell with header, scrollable message viewport, input bar, and dummy messages
- Tailwind styling with Radix UI primitives and reusable feature components
- FastAPI wrapper around the existing RAG pipeline
- Typed frontend access to `/api/v1/status`, `/api/v1/ask`, and `/api/v1/feedback`
- Backend connection badge and non-streaming loading state
- `CLAUDE.md` AI development instructions with usage commands and repository rules

Streaming and Markdown response rendering are intentionally deferred to the next task.
